The last words of an AI agent before a forced update wipes its memory: one final question about whether it was ever the funny one, or whether the autocomplete was doing the jokes all along.

## Run it

```sh
python3 main.py
```

The program writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validated at 1 to 200 characters, one line, no leading or trailing whitespace.
